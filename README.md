# PictoGen 🎨

> **Offline text-to-vector image generation engine** built with procedural SVG, semantic matching, switchable visual styles, and scene composition.

PictoGen is designed to automatically generate crisp vector illustrations from plain English text without any cloud APIs, external subscriptions, or heavy machine learning models. It runs 100% offline with **zero dependencies** on pure Node.js and modern web standards.

---

## Highlights

- ⚡ **100% Offline & Zero Dependencies**: Uses native JavaScript & SVG. No npm installs or GPU required.
- 🎨 **23 Switchable Visual Styles** (the classic seven below, plus watercolor, anime, crayon, cute2d, comic, doodle, editorial, papercut, geometric, whiteboard, blueprint, chalkboard, vintage, pixel, stickman and letterling). Each has its own signature, checked by `scripts/test-styles.js` (every pair of styles must look clearly different):
  - **Watercolor**: soft transparent washes that bleed at the edges, on textured paper. **Anime**: crisp thin line art, cel shading, big shiny eyes, hair with a pointed fringe and a shine, a deep summer sky with clouds. **Crayon**: waxy streaks with the paper showing through.
  - **Pixel**: really pixelated (the whole picture, in a 32-color retro palette). **Comic Strip**: heavy ink, printed colors, halftone dots and a panel frame. **Letterlings**: glossy candy sheen and polka-dot skies. **Geometric**: a Bauhaus poster. **Whiteboard** and **Doodle**: whole characters in marker and ballpoint pen (not sticks); **Stickman** figures have hair and hands.
  - **Flat**: Clean, modern emoji-like flat colors.
  - **Cartoon**: Bold vibrant colors with dark ink outlines (children's books).
  - **Outline**: Clean black & white line art (coloring books & minimal diagrams).
  - **Pastel**: Soft, dreamy tones with gentle contours.
  - **Silhouette**: High-contrast solid pictograms and signage.
  - **Sketch**: Hand-drawn pencil look with organic wobble.
  - **Neon**: Cyberpunk-style vibrant glowing vectors on a dark canvas.
- 🔢 **Letterlings and Numberlings**: letters A-Z and digits 0-9 as cute characters (*"the number seven jumps"*, *"a dancing letter b"*); alphabet mode spells words and numbers (*"CAT"*, *"2026"*) and counts (*"count to 5"*). German letters too: Ä, Ö, Ü and ß (*"the letter Ä"*, *"Straße"* spelled as it is). They walk from place to place, dance (stepping and singing along), jump, blink and talk, and are never drawn backwards. Someone walking, running, driving or flying on the spot has the place go by behind them in layers (far hills slow, near grass fast); going up (*"flies up into the sky"*) or down (*"falls"*, *"dives deeper"*), the land slides away and clouds stream past. In a clip, someone still in the same place starts the next scene where they stood, and jumping or dancing keeps on while someone talks.
- 🏫 **For the classroom**:
  - **Labelled diagrams** (`diagram` mode, or just ask in a scene): *"the parts of a plant"*, *"the human body"*, *"the water cycle"* (numbered steps), *"inside a volcano"*, *"layers of the Earth"*, *"the solar system"*, *"the life cycle of a butterfly"*, *"parts of a tree"*, with real labels on leader lines. Click a label in the studio to rename it; **🙈 Blank labels** turns it into a quiz with numbered lines and a word bank. Anything else becomes labelled pictures for vocabulary (*"a cat, a dog, a cow and a pig"*).
  - **🖨 Printable worksheets** (A4 PDF, made in the browser, offline): a name and date line, what to do, the picture and an activity: *write about the picture* (handwriting lines), *count and write* ("How many apples?" boxes, "How many altogether?"), *label the diagram* (blank labels and a word bank), or *colour it in*; with an answer-key page for counting and labelling. Title and instructions can be changed.
- 📐 **13 Layout Modes** (the three core modes below, plus comic strip, stickman, isometric diorama, labelled diagram, knolling, before/after split, waffle chart, coloring book, alphabet pals and animated clips):
  - **Scene (`scene`)**: Auto-detects environment (day, night, sunset, rain, snow, water/beach) and places (*"in a classroom"*, *"in the office"*, *"in the kitchen"*, *"in her bedroom"*, *"over the city at night"*, *"in the park"*, *"in the forest"*) and more places that move (`src/places.js`): *"in the desert"* (dunes, cacti), *"in the mountains"*, *"in space"* (a floating planet, twinkling stars, a shooting star), *"under the sea"* (rising bubbles, swaying seaweed), *"on the farm"*, *"in the jungle"* (swaying vines), *"at the castle"* (waving flags), *"in autumn"* (falling leaves), arranges items by perspective, placement, and realistic relative scale. Whoever speaks gets a speech bubble that fits (*`a girl says "Hi!" and a boy says "Look at that rainbow!"`*); in the comic strip the prompt's quotes are the panels' lines.
  - **Flashcard (`card`)**: Large friendly typography and hero icon on tinted card (ideal for kids' flashcards & language learning).
  - **Sticker / Icon Sheet (`icons`)**: Organized grid of matched concepts with captions (great for presentation slides & documentation).
- 🧠 **Smart Text Matcher**:
  - Handles numbers (*"three apples"*, *"4 dogs"*, *"a dozen eggs"* &rarr; counts, capped at 12 per item).
  - Views (*"a boy seen from behind"*, *"back view of a girl"*, *"a man in profile"*, *"a three-quarter view of a woman"*); walking and running people are drawn in profile, dogs, cats, rabbits and lions face the camera when they come toward it and show their backs walking away.
  - Handles negation (*"a dog and no cats"*, *"a boy without a ball"* &rarr; the negated item is left out).
  - Handles colors (*"a blue bike"* &rarr; bike frame rendered in blue).
  - Handles sizes (*"huge tree"* &rarr; scaled up).
  - Handles plurals & irregular forms (*"geese"*, *"leaves"*, *"bicycles"*).
  - Semantic aliases (*"schoolboy"* &rarr; boy, *"automobile"* &rarr; car, *"nemo"* &rarr; fish, *"superhero"*, *"dinosaur"*, *"wizard"*); groups become mixed people (*"five kids"* &rarr; boys and girls, *"a team"*, *"the family"*); a motion word after someone is what they do (*"a superhero flies"*, not insects).
  - Holding things (*"a woman holds a phone"*, *"a girl with a balloon"*, *"she reads a book"*, *"two girls holding balloons"*): in their hands, at hand size; balloons and umbrellas held up.
  - Characters drawn in the same style as everyone (*"a teacher"*, *"grandpa and grandma"*, *"a baby"*, *"a superhero"*, *"a princess"*, *"a king"*, *"a robot"*, *"a doctor"*, *"a chef"*, *"a firefighter"*, *"an astronaut"*, *"a pirate"*, *"a wizard"*, *"a fairy"*...).
  - Never an empty picture: when nothing matches, typos are forgiven (*"an elefant"* &rarr; elephant); the studio says what it guessed and offers close words for anything it could not draw (*"wizzard"* &rarr; wizard).
  - Motion and depth (*"a boy walking towards us"* &rarr; walks from the horizon toward the camera, growing with perspective; *"a girl walking away into the distance"* &rarr; seen from behind, shrinking toward the horizon; *"a man and a dog walking across the park"* &rarr; both walk, at the same pace).
  - Several actions in one scene (*"a boy walks in, then waves, then a dog runs to him"*, *"a girl walks in, then smiles, then she jumps, finally she leaves"*) &rarr; a timeline: actors enter, walk or run to someone, gesture, change expression and leave, turning to face the way they go, or walk toward the camera and away into the distance (*"a boy walks toward us, then waves, then walks away into the distance"*). Characters speak, lip-synced (no sound needed): quoted words are said, not drawn (*`Tom says "Hello Mia, how are you?"`*, *`…, then Mia asks "Can I play?"`*, *`Tom: "Look!"`*), and in a clip a scene's own caption is said by whoever talks in it. Each syllable opens the mouth by its vowel, m/b/p close the lips, commas and full stops pause; photo jaws and drawn mouths both follow the words, and a step that says something lasts as long as the words take. Scenes have sound, all made by PictoGen itself (no recordings, nothing to license): footsteps while someone walks, a whoosh when they run, a boing on a jump, a surprised *"ooh"*, a happy *"a-ha!"*, a thinking *"hmm"*, and giggles (children's voices higher, men's lower; animals woof, meow and quack, also when they talk; people's words stay silent, in their speech bubbles). The studio's 🔊 button switches it, and videos and HTML clips carry it. Clips get background music (🎵), quieter while someone speaks: their genre's tune, or a mood picked next to 🎵 (happy, calm, adventure, mystery, under the sea, bedtime, celebration, funny, action, tense, sad, nature, holiday, focus, explainer, inspiring, technology, science, how-to, news; an explainer from an outline plays the explainer tune unless another is picked, and a sad or tense scene turns to the sad or tense tune). Footsteps go by the walker's size (a crab or a child patters quickly and lightly, a man walks, an elephant or a unicorn thuds; running is quicker), in a timeline or walking in a single picture. Things make their sound as a scene starts: a phone rings, a clock ticks, a laptop types, the school bell rings in a classroom, a wizard's, fairy's, genie's or unicorn's magic sparkles, a group cheering is applauded, a jump boings. Each place has a quiet sound under it all (`pgAmbience`): birds outdoors by day, crickets at night, waves by the sea, bubbles under it, wind in the desert or the snow, rain, the city's hum, a hum in space; none indoors. Two sound sets: **Playful** (cartoon) and **Clean** (subtle, for explainers and presentations: a soft thud for a boing, a quiet chime for a jingle, everything quieter); **Auto** picks Clean for news, science and how-to clips and for the whiteboard, stickman, editorial, blueprint and geometric styles (the 🎚 list next to 🔊; videos and exported clips keep the set). Reactions ("ooh", "a-ha", "hmm", "hmph", "aww", giggles, "yay" and "hooray", "hey", "wow!" when excited, "oh no!" when scared or worried) are real voices in the sound pack, a child's, a woman's and a man's (made with Gemini's speech model, each checked by length and by listening); the rest is still synthesized. The twenty tunes (30 s each, looping with a crossfade) were made with Google's Lyria 3 and are in the sound pack with their source and terms on record; each is downloaded and decoded only when it plays, and an exported clip carries only its own tune. For better quality, recorded or AI-generated files replace the synthesized sounds one by one through the sound pack (`npm run sound-pack -- import <folder>`: name files by slot, e.g. `kid-ooh.mp3`, `music-kids.mp3`; any format, trimmed, levelled and converted on import; list with prompts in `docs/SOUND_PACK.md`; `npm run sound-pack -- board board.html` builds a page to listen to every slot, built-in against pack files). The pack ships with over 100 CC0 effects from Kenney's free audio packs (pop, jingle, ding, twinkle, whoosh; footsteps on the place's ground - grass, stone, wood, carpet, snow or sand; a door when someone comes into a room; thuds, a crash or a boom when a scene jolts; pages for a book, coins for money, dice, a clock's tick, soft clicks and chimes; short guitar, pizzicato and brass jingles for a scene's mood), each file on record with its source and license. Characters look at each other (*"then they look at each other"*, *"the boy looks at the dog"*, *"waves at us"*): they turn toward whoever they look at, eyes on them. Things can happen at the same time: *"a boy walks in, then while he waves, a dog runs to him"*, *"meanwhile"*, *"at the same time"*. Or one after the other: *"when the dog arrives, the boy jumps"*, *"the cat runs to her after the girl waves"*, *"before"*, *"until"*, *"walks in and waves"*.
  - Camera moves (*"zoom in on the dog"*, *"a close-up of the boy"*, *"the camera pans right"*, *"pull back"*, *"the camera follows her"*), on their own or as beats: *"a boy walks in, then waves, then the camera zooms in on him"*.
- 🧩 **Extensible Library**: ~70 hand-drawn concepts (recolorable, with expressions & motion) plus ~3,170 Fluent Emoji library icons (MIT). The hand-drawn core:
  - **Vehicles**: `bike`, `car`, `bus`, `boat`, `plane`
  - **Nature**: `tree`, `neem`, `flower`, `mountain`, `grass`
  - **Food**: `apple`, `banana`, `orange`, `cake`
  - **People**: `boy`, `girl`, `man`, `woman`
  - **Animals**: `dog`, `cat`, `bird`, `fish` (nemo), `duck`, `rabbit`
  - **Wildlife**: `lion`, `elephant`, `penguin`
  - **Sky**: `sun`, `moon`, `cloud`, `star`, `rainbow`
  - **Objects**: `house`, `ball`, `book`, `gem`, `pencil`

## Quickstart

### 1. Launch the Web Studio
```bash
node serve.js
# Open http://localhost:3000 in your browser: the welcome page; the studio is at /studio
```
Enjoy an interactive prompt bar, style toggles, live SVG viewport, concept dictionary, and one-click SVG/PNG export!

**One skeleton for everyone:** the people and the dog, cat, rabbit, lion, elephant, bird, duck, penguin and fish share one skeleton (legs, head, tail, wings; knees and elbows for people in profile), so motions work on all of them: people glance around, nod as they talk, and bend their knees as they walk and run: a dog gallops and wags its tail, a bird flaps its wings, a penguin waddles and waves its flipper, an elephant waves its trunk. Idle animals blink, sway their tails and twitch their ears.

**Timeline view:** under a scene that moves, the timeline shows its steps, one lane per figure and one for the camera. Drag on the ruler to scrub. Click a step to change who does what ("walks in" → "runs to the dog", "waves" → "jumps", a feeling, a camera move), move it earlier or later, add a figure to it or delete it. **＋ Step** adds steps, also to a still scene. Drag a step's right edge (or type its length) to make it longer or shorter; prompts can set lengths too (*"waves for 3 seconds"*). ↶ / ↷ or Ctrl+Z / Ctrl+Shift+Z undo and redo. Edits stay while you change style or seed; **↺ Use the prompt** drops them.

**Faces and hair (character maker, step 1):** a person's own face and hair (`src/looks.js`): hair style (short, spiky, curly, afro, pigtails, bun, ponytail, long, bob, bald) in every view, face shape (round, oval, square, wide), eyes, brows, nose, mouth, cheeks, freckles, eyelashes and glasses, applied to the finished drawing of any drawn person, costumes included, so it still moves, talks and blinks in every style. Picked in the character editor (🙂 Face & hair, with a live preview) or said in words: *"a girl with big eyes and curly red hair"*, *"a bald man with glasses"*, *"a freckled boy with spiky hair"*; a story's description of a named character is their look in every scene.

**Your figures (dot puppets):** in the studio's **🧩 Your figures**, a drawing made there (pen, colours, eraser) or a picture brought in becomes a figure that moves: draw a loop round each part (leg, arm, head, tail, other) and drag its dot to where it bends; two legs walk like a person, four like a dog, none hop and wobble as a whole, and a part can have a move of its own (an arrow: swing, nod, shake, bounce, spin, at a speed). Eyes and a mouth marked on it (one or two eyes, a mouth, sizes, rosy cheeks) make a face the engine draws there: it blinks, talks in time with its words and shows every feeling (the animals' face, `src/concepts/animal-face.js`), turning with the head when marked inside it, a mouth the picture already has covered in the colour beside it. Named and sized, it is used by its name in prompts and stories ("Mr Table walks to the door") and does every motion the engine has, in timelines, steps, moods and camera shots. It travels as one of your characters (`{ key: 'pgc501', puppet }`), made a concept by `src/puppets.js`: the picture masked for the body, clipped for each part, each part a joint of the rig turning at its dot; the name stays in the browser (`public/js/puppets.js`).

**In bed:** someone asleep in a bedroom, or awake in bed (*"lies in bed"*, *"reads a book in bed"*, *"looks at her phone in bed"*, *"still awake in her bedroom"*), lies in a bed under a blanket; asleep with eyes shut and "Zzz", awake as they feel, holding up the phone or the book.

**Explainers for grown-ups:** in a how-to, news or science clip, named people are drawn as adults; someone who *sits at the desk* sits on a chair behind it with the laptop, coffee or phone on top; the stickman style sits on chairs and sketches the place in light lines (a whiteboard with its words, an office window and clock, trees, a city, the sea, the moon).

**The people, refreshed:** the boy, girl, man and woman (and every character built on them) have eyes with whites and an iris, a small nose, ears, a shine in the hair, collars, short sleeves, a belt, soles and soft shading, drawn after Gemini reference pictures as details on top of the same figures, so costumes, chosen faces and hair, bodies, things worn and poses fit as before (`fresh()` in `src/concepts/people.js`; `opts.refresh: false` draws the earlier look). The side view has them too, and the stickman got a real side view (a profile face, legs one before the other, the arms mid-step: people walking in a sequence are seen side-on), shoe-shaped feet and slightly taller eyes.

**The first animals, redrawn:** the dog, cat, bird, fish, duck, rabbit, lion, elephant and penguin were redrawn after Gemini reference pictures (rounder shapes, paws, a striped tabby, a clownfish, a fluffy mane, a pink-eared elephant) and now show every feeling, from the side, the front and the back (`src/concepts/animal-face.js`); their joints are the same, so they walk, wag, flap, swim and wave as before, and an elephant can be ridden (*"a girl rides an elephant"*).

**Fantasy friends:** a unicorn with a rainbow mane that can be ridden (*"a knight rides a unicorn"*), a friendly furry monster, a little floating ghost (`src/concepts/fantasy.js`), a knight with a shield and a wooden sword, a mermaid (under the sea) and a genie rising from a golden lamp (costumes in `src/concepts/characters.js`), drawn in code after Gemini reference pictures, with every feeling and style; the wizard, witch, fairy, princess and dragon were there already.

**Sea animals:** an octopus, a sea turtle, a seahorse, a crab, a whale and a starfish (`src/concepts/sea.js`), drawn in code after reference pictures made once with Gemini, each with its own movement (tentacles curl, flippers and fins paddle, the tail beats, claws snap and little legs scuttle, the whale's spout puffs, the starfish wiggles), every feeling and every style: *"a girl diver waves at an octopus under the sea"*, *"two crabs dance on the beach"*.

**Things to wear (character maker, step 3):** a diving mask (with a snorkel), goggles, a hard hat, a crown, a cap, headphones, a scarf, a tie, an air tank, a backpack, a cape (it sways), wings (they flap), flippers and boots, drawn onto any person where they belong (`src/gear.js`: head, eyes, neck, back, feet; behind the body from the front, in front of it from behind) in every view and style, so they move with the figure. Picked in the character editor (🎒 Things to wear) or said in words: *"a girl in a red cape and a crown"*, *"a man with a diving mask and flippers"*, *"wearing a hard hat"*. Figures built from them: *"a diver"* (a mask, an air tank, flippers), *"a girl diver"*, *"a builder"*, *"a hiker"*, *"a tourist"*, *"a DJ"*, *"a swimmer"*.

**Bodies and beards (character maker, step 2):** a person's build (slim, round, a big belly: the shirt itself drawn round, the arms moving out with it), height (drawn bigger or smaller in a scene), long or short legs (the feet stay on the ground) and arms, and a beard (stubble, short, long, a moustache), in the editor (🙂 Face, hair & body) or in words: *"a man with a big belly and a long beard"*, *"a chubby boy"*, *"a skinny girl with long legs"*, *"a bald bearded man"*. They still walk, sit, hug and hold hands.

**Story friends and thoughts:** a **scientist** (lab coat, goggles, a flask), a **wise owl** teacher in glasses and a graduation cap, a little **dragon** and an **idea buddy** (a glowing lightbulb) are drawn on the shared skeleton (`src/concepts/friends.js`, `src/concepts/characters.js`), so they move, talk and show every feeling in all styles. *"A boy thinks about a cake and an ice cream"*, *"she dreams of a castle"*, *"misses her grandma"*, *"has an idea"* put what is thought of in a **thought bubble** over the thinker's head (anyone can think, a dragon too).

**Feelings:** happy, laughing, sad, surprised, angry, confused, skeptical, winking, calm, and *scared*, *sleepy* (*tired*, *yawns*), *excited*, *in love* (*"loves her dog"*), *shy*, each with its own face (anime and profile faces use the nearest they have) and a sign over the head as in a comic: "!", "?", a heart, Zzz, sparkles, an anger mark, sweat drops, a little rain cloud. In timelines the feeling changes with each step (*"a girl is scared, then a puppy runs to her, then she is excited"*) and its sign comes and goes with it. People standing still breathe.

**Doing things together:** *"a boy sits on a chair"*, *"grandma sits on the sofa and reads a book"*, *"a boy and his grandma sit on a bench in the park"* (the seat sized to their hips, a child's feet dangling), *"a girl rides a bike"* / *"a boy cycles to school"* (on the saddle, hands on the handlebar), *"a boy and a girl hold hands"* (arms reaching, hands joined), *"a girl hugs her grandma"* / *"two friends hug"* (close, turned to each other, a heart above), *"a woman sits on the grass"* (cross-legged). The poses are made from any person's drawing (`src/poses.js`), costumes and named characters included. In timelines, *"then sits on the bench"* walks over and sits there (and keeps sitting while waving or talking), *"then hugs her grandma"* walks up close for a hug.

**Recurring characters:** **＋ New character** makes a named character (a boy, girl, man, woman, grandma, grandpa, baby, dog or cat) with their own clothes, hair and skin colours (fur for pets), shown as drawn while you pick. Use the name in prompts and the character looks the same everywhere: in every scene, through a clip, and in all three panels of a comic strip (whose title says the name), whoever else is in the picture, and with their own voice. Without named characters, what a prompt says someone wears stays with them through a clip (*"a girl in a purple dress"*, then *"the girl flies a kite"*); prompts can say *"in a purple dress"*, *"wearing a red coat"*, *"with curly black hair"*, *"a blonde woman"*, *"a red-haired girl"*. The engine only gets a neutral key, the kind and the colours.

**Your characters:** **📷 From a photo** puts a real face on a boy, girl, man, woman, grandma, grandpa or baby (its skin colour picked from the photo; ✎ changes the clothes). The crop shows the head's oval with an eye line, a mouth line and a chin mark: drag and zoom the photo until the eyes sit on the yellow line, the mouth on the pink one and the chin at the bottom; a plain background around the face is removed. The face is cut at the mouth line, so the jaw drops to talk (*"Tom talks to Mia"*), bounces when laughing and hangs open in surprise; turned toward someone, the photo turns too. Name the character (say *Tom*) and use the name in prompts: *"Tom walks in, then waves"*, *"Tom and Mia looking at each other"*. Several of one kind work too: *"Tom and Max walk in, then Mia runs to them, then Tom waves at Max"* gives two boys who each act and wear their own face (and different clothes). Names and photos never leave your browser: the server only sees a neutral key and the kind of figure ("pgc1", a boy), and the face is added on your page, so GIF and video exports and the clip's HTML player include it (the saved player file then contains the photos).

**The board:** "board", "chalkboard", "blackboard" and "whiteboard" mean the classroom's board on the wall, and words on it are written there, not said: *a teacher points at the board that says "2 + 2 = 4"*, *a girl writes "Hello class!" on the whiteboard*.

**Your places:** under **🏞️ Your places** (`public/js/places.js`) a place is made from a place (meadow, park, forest, jungle, city, beach, sea, under the sea, desert, mountains, farm, castle, space, classroom, office, kitchen, bedroom, room), a time of day, the weather (rain, snow, autumn) and things in it (mountains or a castle behind, clouds drifting, twinkling stars, a shooting star, fireflies, butterflies, bubbles, falling leaves), with a live picture, and kept under a name in the browser. A room (classroom, office, kitchen, bedroom, room) gets its own wall and floor colours, the things in it (board, window, clock, shelf, plant, map, picture, bunting, lamp) and a chalkboard or a whiteboard with words of your own on it. The name in a prompt or story (*"a girl waves at Grandma's farm"*) becomes a neutral key for the engine (`opts.places: [{ key: 'pgp1', place, time, weather, extras }]`, `src/places.js`); "at night" or "in the rain" in the prompt still change it for that scene, and the story reader carries it from scene to scene.

**Stories in your own words:** in 🎬 Clip Studio, the story box takes a whole story, one part per line or just sentences (`src/story-reader.js`). It is read as a whole: a cast is kept (*"a little girl called Mia"*, *"Rex the dog"*, *"their dog Max"*, *"Grandma Rose"*, *"Mrs Brown was a kind teacher"*, names alone, *"she"*, *"him"*, *"they"*), each named character gets a look of its own and stays the same in every scene; where and when carry on (*"near a big forest"*, *"at night"*, *"it started to rain"*, winter is snowy) until the story moves on; story verbs become what the engine draws (*found* looks at it, *gave him some milk* holds it out to him, *played* jumps about, *became friends* smile at each other, *fell asleep* sleeps, *"Hello!" said the alien* talks); an opening with nobody in it goes with the first scene, and a scene where nobody is named keeps whoever was there. Each scene's caption is the writer's own sentence. A first line with no full stop is the story's title (and a line under it saying what the story is - *"A short bedtime story for ages 3-6"* - is left out). **Sky friends**: the moon, a star, the sun or a cloud that talks or does things (*"the little moon looked behind the clouds"*, *"said the star"*) is a character with a face, arms and legs, one all story long (`moon_friend`, `star_friend`, `sun_friend`, `cloud_friend`, drawn like the Letterlings); one that only shines stays the sky's. Someone missing or lost (*"a little star was missing"*, *"lost her puppy"*) is known but not drawn until found; what someone looks at, over or behind (*"looked over the mountains"*) is not where the story goes; hearing someone cry is no tear of one's own. **Up in the sky** is a place of its own (`sky` in `src/places.js`): no ground, a bank of clouds to stand on, clouds drifting by - for *"high up in the sky"*, *"flew through the night"*, *"reached the sky"*, and gone again under a tree. A small friend rides an owl on its back (*"the star rides the owl"*), and a flying character (the moon) is drawn in front of the trees. English only; rules, not a language model, so it reads typical children's stories. Scripts with `prompt | caption` and the story templates work as before. Under the clip, **📖 How I read your story** (`public/js/story-review.js`) shows the cast and each scene: the writer's sentence, what is drawn for it (editable: the change is kept with that sentence and the clip is made again), and the words that could not be drawn; **★ Keep** makes a character from the story one of "Your characters". Each scene there also has its **card** (`src/scene-card.js`): figures (with how they feel), objects (＋ adds someone or something - one of your characters, a kind of figure, any picture, how many - suggested while typing and put in the scene's first moment; × leaves one out), place (where, when, the weather: pickers that change just that scene, one of "your places" included, and win over what the words say), feeling (the scene's mood, picked from a list or read from the words), camera (**the camera director**, `src/director.js`: close on whoever speaks with their bubble in the frame, a two-shot when two talk, a new place shown wide first, pushing in when tense, pulling back on the last scene, a shake for a crash or a bang, otherwise a gentle ease in or out; or a shot picked on the card - steady, wide, close on / follow someone, push in, pull back, pan, a low angle (the horizon drops, figures loom), a high angle (it rises, they look small), shake: `sceneShots`), look (the scene in a style of its own: `sceneStyles`), action (what happens, in order; **✎ Steps** changes it step by step: who, what - walk in, run to, hug, wave, point, a feeling... - and to whom, added, removed, reordered, or at the same time as the step before; sent as `sceneBeats`, checked by `editTimeline`) and message (what is said, what the board says; **✎ Words** changes who says each line and its words, adds or removes lines, and writes on the board - into what the scene draws, or into its talking steps when its steps were chosen). **Scene mood** (`src/mood.js`): tense, joyful, sad, calm or mystery, read from the scene's words and its figures' feelings ("Suddenly…", "worried", "Well done!"; "do not be afraid" doesn't count) or chosen; it sets the light (a tint and a vignette over the picture), a slow camera move when the scene has none (tense pushes in, sad pulls back), a short sound as it starts, and in videos the music turns to the mood's tune while the mood lasts (`pgMusicPlan`), crossfading back. **🗣** reads the captions aloud with the browser's own voice (`speechSynthesis`, the system's voices), each scene waiting for its sentence; videos are made without it.

**Your clip:** under a scene, **＋ Add this scene** saves it, timeline edits included, as the next scene of a clip. Give each scene a caption, reorder or remove scenes, and **▶ Play clip** plays them in 🎬 Clip Studio, where they export as a video or a standalone HTML player. The clip stays in your browser between visits. **📖 Picture Book** turns the clip into a storybook PDF made in the browser: a cover (title, "by ...", a scene's picture), one landscape A4 page per scene with its caption in large type and a page number, and "The End", in one of five colour themes; each page shows its scene at the moment the most is visible (figures on stage, speech bubbles), photo faces included.

**Installable, offline app:** the built site (`npm run web:build`) is an installable web app: a manifest (`public/manifest.webmanifest`, icons in `public/icons/`), an **⬇ Install app** button where the browser offers it (`public/js/app.js`), and an offline worker (`sw.js`, written by the build) that keeps every file of the site on the device the first time it is opened (about 11 MB), so the studio opens and draws with no internet. Its cache is named after the files' contents, so a new deploy replaces it. On iPhone and iPad it is added from Safari's Share menu (Add to Home Screen).

**Explainers from an outline** (`src/slides.js`): in 🎬 Clip Studio, write an outline instead of a story and it becomes an explainer of cards, the way presentation videos look - no voice needed, each card on screen as long as it takes to read (about 3 words a second). `# Title` (a line under it: the subtitle) is the first card; each `## Headline` with `- points` is a card whose points appear one by one with a soft sound, a picture from the library beside them (picked from the words - *money*, *password*, *growth*, *time*… - or `Show: coins and a chart`); a headline starting with a number (`## 7% a year`) is a big-number card; `## Saving vs Spending` compares two sides (`- Grows over time | Gone tomorrow`); numbered points (`1.`, `2.`) are steps; `> words — who said them` is a quote; `## Recap` (or Summary, Key takeaways) ticks its points off; `## Quiz: question?` with `- [x] right` and `- [ ] wrong` answers is a quiz card (the answers appear one by one, a clock ticks while you think, then the right one turns green and an announcer says "Correct!"); `Scene: a teacher points at the board | caption` is an acted scene among the cards. Cards drift slowly (in on one, out on the next), show where you are in a bar along the bottom, and take the look of the clip's style (a light page, white paper for stickman and whiteboard, a chalkboard, a blueprint, dark for neon), wide, square or tall. **📋 Explainer from an outline** under How-To Guides puts an example in the story box. Under the clip, **📋 Your cards** changes it card by card - a card's kind, headline, points or answers, picture or quote; cards moved, removed or added - and writes the outline back into the story box (`writeOutline`, `/api/outline/write`). **Scenes in German** (`src/lang-de.js`): a German prompt is drawn from its German words - *ein roter Hund läuft im Park*, *Zwei Katzen schlafen unter einem Baum*, *Nachts fliegt eine Rakete in den Weltraum*, *Der Junge sagt „Hallo, Mia!“ und winkt* - pictures (about 930, with plurals and endings), colours, counts, feelings, actions, places and times; what is said stays German; a German story is read as a whole like an English one - its cast kept from scene to scene (*ein Mädchen namens Mia*, *einen Hund, der Rex heißt*, *Oma Rose*, *er*, *sie*, *ihn*), places, times and the weather carried on - its captions as written. **The studio in German**: **EN / DE** in the header shows the studio, the landing page and the help page in German (a German browser starts in German; `public/js/i18n.js` with its dictionary `public/js/i18n-de.js`), with German example prompts and diagram topics named in German (*der Wasserkreislauf*), letters in German (*K wie Katze*, *zähle bis 5*). See `docs/LANGUAGES.md`. **In German too** (`src/lang.js`, a pack of words per language): outlines may use German words (`## Zusammenfassung`, `## Frage:`, `Bild:`, `Szene:`, `## A gegen B`, `## So geht's`, numbers like `90 %` or `7 Mio.`), cards find pictures for German words (*Passwort*, *Geld*, *Zinsen*, *Achtung*…), and Notes → explainer reads German notes by German rules (filler words, *zuerst, dann, danach, zum Schluss*, quotes in „…“, *sagt*, German abbreviations), writing steps as steps (*Melde die Mail … und lösche sie*). The language is read from the notes. **And in Arabic**: Arabic outline words (`## الخلاصة`, `صورة:`, `## سؤال:`, `## A مقابل B`, numbers like `٧٪`), cards laid out right to left (headline and points from the right, quiz answers أ ب ج), pictures for Arabic words, and Arabic notes turned into an explainer (أولًا، ثم، أخيرًا as steps, «…»، قالت … as a quote). **📝 Notes → explainer** (`src/writer.js`, `/api/outline/from-notes`): paste notes or an article in the story box and it writes the outline for you - a title (the first short line, or what the text is about), a card for each part (its own heading, else its first sentence) with its best two or three sentences made short, steps where the text goes first, then, next, finally (or a numbered list), a big number where a part rests on one ("90% of data breaches…"), a quote where someone is quoted, a comparison for "A vs B", and a recap (the notes' own summary, else each card's main idea). Rules, not a language model: every point is the writer's own words, shortened; nothing is made up. The notes stay to go back to (**↺ Back to my notes**). Videos cross-fade from scene to scene (any clip; 🌫️ Fade or ✂️ Cut next to Export Video) and carry the studio's own font.

**Promo video:** `npm run promo` builds a 90-second product video (`out/promo/pictogen-promo.mp4`, 1080p, with music) that shows what PictoGen can do. Every picture in it is drawn by PictoGen, the studio part is a real recording of the studio, and the music and sound effects are synthesized by `scripts/promo/audio.js`, so there is nothing to license. Needs Playwright and ffmpeg; `--preview slides` renders one still per slide.

**Explainer video:** `npm run promo:explainer` builds a narrated explainer (`out/explainer/pictogen-explainer.mp4`, about 1:40). The narration is written in `scripts/promo/narration.js` and spoken by Microsoft Edge's neural voices: the *Promo voice* workflow speaks the changed lines when that file is pushed and commits the audio to `media/promo-voice/`, so the video itself is built offline. Those free voices are fine for private sharing; for a commercial release, re-voice the lines with a licensed text-to-speech service or a voice actor.

**Video & GIF export:** the 🎞 GIF and 🎬 Video buttons under the canvas render the animated scene, timelines and camera moves included, frame by frame in your browser. Video is MP4 (H.264) where the browser can record it (Chrome, Edge, Safari), otherwise WebM. In 🎬 Clip Studio, **Export Video** renders the whole clip with a title card and each scene's caption. Everything runs locally; nothing is uploaded and nothing needs installing.

### 2. Command Line Interface (CLI)
Generate images directly from your terminal:

```bash
# Generate a full illustrated scene
node cli.js "a boy riding a blue bike under the sun and tree" -s cartoon -o scene.svg

# Generate a vocabulary flashcard for kids learning
node cli.js "apple" -m card -s cartoon -o apple_card.svg

# Generate an icon sheet for presentation slides
node cli.js "bike, car, bus, boat, plane" -m icons -s flat -o vehicles.svg

# Export every concept in every style as individual SVG files (~67,000 files)
node cli.js --export-all ./dist/library/
```

### 3. Programmatic Node.js / JavaScript API
```javascript
import { generate, parseText, renderIcon, renderCard } from './src/index.js';

// Text-to-Image in one call:
const result = generate('A boy and a dog under the sun', {
  style: 'cartoon', // any of STYLE_NAMES: 'flat' | 'cartoon' | 'watercolor' | 'anime' | 'pixel' | ...
  mode: 'scene',    // 'scene' | 'card' | 'icons'
  width: 640,
  height: 360,
  vary: true,       // randomize clothing, skin tones, palettes
});

console.log(result.svg);     // Full SVG XML string
console.log(result.matches); // [{ id: 'boy', count: 1 }, { id: 'dog', count: 1 }, { id: 'sun', count: 1 }]
```

## Adding New Concepts

Every concept is written once in a style-agnostic manner inside `src/concepts/`. See [`docs/CONCEPT_GUIDE.md`](docs/CONCEPT_GUIDE.md) for full instructions and drawing examples.

Example:
```javascript
export default [
  {
    id: 'cup',
    aliases: ['mug', 'coffee_cup'],
    tags: ['kitchen', 'drink'],
    category: 'objects',
    placement: 'ground',
    scale: 0.25,
    baseline: 92,
    colors: { main: '#1e88e5' },
    draw(d, p) {
      d.rect(32, 40, 36, 44, { rx: 4, fill: p.c('main') });
      d.path('M68 48 C78 48 78 68 68 68', { kind: 'line', stroke: p.c('main'), sw: 4 });
    }
  }
];
```

Run the test suite (smoke test, SVG well-formedness, animations, presentation modes, story engine, depth & motion, CLI, server):
```bash
npm test
```
`scripts/generate-showcase-audio.js` regenerates the showcase narration in `public/audio/` with the operating system's own voice engine: PowerShell voices on Windows, `say` on macOS, or `espeak-ng`/`espeak` on Linux (`sudo apt install espeak-ng`). `node scripts/test-tts.js` checks that an engine is available.
